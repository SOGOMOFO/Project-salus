## Primary Daily Flow
Morning:
1. Open /command/workflows.
2. Run the morning checklist.
3. Open /command/daily-driver.
4. Open /command/ops to create records.

Evening:
1. Open /command/workflows.
2. Run the evening closeout checklist.
3. Open /command/review.
4. Open /command/records if cleanup is needed.

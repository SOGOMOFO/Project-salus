# Sprint 07 — Real Daily Use Mode

## Objective
Move Project Salus from development/testing into real daily use by Kyle.

## Problem
The backend works, the dashboard works, missions work, AARs work, persistence works, and reset controls work.

Now Salus needs to support a real daily operating rhythm:
- morning command brief
- real mission entry
- mission review
- evening AAR
- simple dashboard use

## Must Ship
- Cleaner command dashboard layout
- Real Daily Commander Brief flow
- Real mission entry/update flow
- AAR entry flow
- Clear separation between dev/test reset tools and daily-use controls

## Do Not Build Yet
- Agent fleets
- Multi-user accounts
- Cloud sync
- LangGraph/CrewAI
- Supabase
- Enterprise features
- Public launch

## Success Criteria
1. Kyle can open /command and run a real daily brief.
2. Kyle can add real missions.
3. Kyle can update mission status.
4. Kyle can log one AAR.
5. Dashboard shows clean real-use state.
6. Tests pass.

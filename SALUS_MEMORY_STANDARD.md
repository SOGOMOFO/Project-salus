# Salus Memory Standard

## Memory Types
- User memory
- Mission memory
- Knowledge memory
- Family memory
- Business memory
- School memory
- Health memory
- Financial memory
- Legacy memory

## Memory Rules
Memory must be:
- relevant
- accurate
- useful
- updateable
- tied to better future judgment

## Bad Memory
Do not store noise, vanity, stale assumptions, or unverified claims as permanent truth.

# Salus Agent Standard

## Required Agent Fields
- id
- name
- mission
- domain
- authority_level
- allowed_actions
- prohibited_actions
- required_inputs
- outputs
- escalation_rules

## Default Agents
- Commander
- Teacher
- Cyber
- Finance
- Health
- Family/Admin
- Intelligence
- Business
- Legacy

## Agent Rules
Agents advise, analyze, teach, and plan.
Agents do not execute irreversible actions without explicit approval.
Agents must distinguish fact, inference, forecast, and speculation.

# Project Salus Phase III — Teaching Engine v1.0

## Objective
Build the first dedicated Teaching Engine for Project Salus.

## Mission
Teach Kyle in a way that increases capability, judgment, independence, and long-term performance.

## Shipped
- backend/services/teaching_engine_service.py
- backend/routes/teaching_engine.py
- /api/teaching-engine/status
- /api/teaching-engine/profile
- /api/teaching-engine/lesson
- /api/teaching-engine/quiz
- /api/teaching-engine/session
- /api/teaching-engine/sessions
- /api/teaching-engine/sessions/{session_id}
- /command/teaching-engine
- Kernel subsystem registry entry

## Teaching Standard
The Teaching Engine should use plain language, small steps, real mission examples, practice questions, brief correction, and capability-building feedback.

## Non-Execution Rule
The Teaching Engine creates learning sessions and practice. It does not execute external actions.

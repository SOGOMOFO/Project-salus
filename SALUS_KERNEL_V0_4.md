# Salus Kernel v0.4 — Response Planner

## Objective
Create a response planner that turns context packets into structured response plans.

## Shipped
- backend/core/response_planner.py
- /api/kernel/plan/status
- /api/kernel/plan

## Plan Includes
- context packet
- intent
- selected subsystem
- response pattern
- approval requirement
- response rules
- next action

## Rule
Planner does not execute. It prepares structured response strategy.

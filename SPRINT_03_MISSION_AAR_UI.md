# Sprint 03 — Mission and AAR UI

## Objective
Complete the local Project Salus command loop in the browser UI.

## Required Loop
Dashboard → Daily Brief → Mission Creation → Mission Update → AAR Log → Dashboard Refresh

## Must Ship
- Create mission from UI
- Update mission status/priority/risk/next action from UI
- Add AAR from UI
- Display AAR list or latest AAR
- Refresh dashboard after actions
- Basic success/error messages

## Do Not Build Yet
- Login
- Multi-user support
- Database migration
- External AI integrations
- Agent orchestration
- Supabase
- Vector database
- Mobile UI
- Public deployment

## Success Criteria
1. Kyle can open /command
2. Kyle can save a daily brief
3. Kyle can create a mission
4. Kyle can update a mission
5. Kyle can enter an AAR
6. Dashboard refreshes after changes
7. Tests pass

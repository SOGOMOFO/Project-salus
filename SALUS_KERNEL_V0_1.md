# Salus Kernel v0.1

## Objective
Create the first central orchestration layer for Project Salus.

## Purpose
The Kernel is the heart of Salus OS. It routes input through identity, memory, intent, judgment, planning, approval, response, and learning.

## Routes
- /api/kernel/status
- /api/kernel/architecture
- /api/kernel/route
- /command/kernel

## Kernel Flow
Receive input → Load identity → Load memory context → Classify intent → Select capability → Apply judgment → Build plan → Require approval if needed → Produce response → Capture learning

## Rule
No autonomous irreversible execution. Human approval remains required.

# Project Salus Kernel Architecture Summary

## Identity
Project Salus is a Human Judgment System for the Intelligence Age.

## Prime Directive
Improve human judgment without replacing human accountability.

## Kernel Pipeline
User request → intent classification → subsystem routing → context packet → response plan → execution gate → doctrine check → orchestration packet → learning recommendation → user-visible response.

## Current State
Kernel v1.0 establishes the local MVP foundation for controlled orchestration.

## Next Strategic Phase
Move from Kernel stabilization to subsystem depth:
1. Teaching Engine
2. Agent Runtime
3. Database Foundation
4. Connector Layer
5. Persistent UI Dashboard
